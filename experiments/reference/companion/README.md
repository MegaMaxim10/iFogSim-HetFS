Result files published in the reproducibility package of the companion paper
(Zekeng Ndadji et al., "Source-Code Analysis of iFogSim for Simulating Distributed IoT
Architectures", arXiv:2604.23122; Zenodo, doi:10.5281/zenodo.22234733), CC BY 4.0.

reproduction experiment (`companion_reproduction`).
