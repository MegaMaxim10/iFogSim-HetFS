================================================================================
  ARCHITECTURAL HIGHLIGHTS
================================================================================

1. Graph-Based Topology
   - Replaces simple parent-child hierarchy with arbitrary graphs
   - Supports mesh and complex network topologies
   - Dynamic routing with Dijkstra algorithm

2. Hardware Abstraction
   - Parallelism multipliers for different architectures
   - Effective MIPS = base MIPS × parallelism degree
   - Realistic power consumption modeling

3. Online Statistics
   - Welford's algorithm for memory-efficient computation
   - No need to store all measurements
   - Computes variance, mean, and confidence intervals on-the-fly

4. Stateful Module Lifecycle
   - onInit: Initialize module with starting state
   - onTupleArrival: Process tuple and update state
   - onCheckpoint: Create state snapshot
   - onRestore: Recover from checkpoint

5. Fault Injection Framework
   - Builder pattern for convenient scheduling
   - Chain method calls for multiple faults
   - Automatic routing table rebuild on changes

6. Energy Modeling
   - Simple physics-based battery model
   - Per-transmission and idle drain costs
   - Sensor lifecycle: operational → exhausted
